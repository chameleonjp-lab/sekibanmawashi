# sekibanmawashi

石の環を回し、発光紋から必要な受光紋へ光を届ける、短時間のブラウザ向けパズルゲームです。

現在は**実装前**です。ゲームコードや90問の本番問題はまだありません。このリポジトリには、調査資料、採用した仕様、画面案、6件のPull Requestに分けた実装計画を格納しています。

## 現在の競技仕様

- 公開版の盤面は12方向、可動環3本です。
- 公開前に初級30問、中級30問、上級30問の合計90問を作り、全問を機械的に検査します。
- 1回の挑戦では、初級2問、中級2問、上級1問の合計5問を出します。
- 日替わり問題は使いません。サーバーが5問を選び、その挑戦の間は問題を固定します。
- 順位は5問の合計時間、総手数、有効記録の送信時刻の順で決めます。

旧資料にある「3問」「16方向」「4環」「同じ期間は全員が同じ問題」という案は採用していません。実装時は`docs/archive/`を仕様の根拠に使わないでください。
