# 試作と現行計画の差

更新日: 2026-09-21

`prototype/`は旧規則の確認用試作です。この文書PRではゲームコードも90問も変更していません。現行の正本は[対応実装計画書 v2.0](../docs/planning/IMPLEMENTATION_PLAN.md)です。

| 項目 | 現行計画 | この試作 |
|---|---|---|
| 操作 | 常時発光・左右回転だけ | 発光切替と停止状態が残る |
| 論理状態 | 回転量だけ、1,728状態 | 回転量と発光状態、13,824状態 |
| 問題庫 | v2で全再検査して90問・900券を採用 | 旧90問・900券。新基準に適合済みではない |
| 実装場所 | 正式版のsrc/contentを基本とする | prototypeに隔離 |
| 画面・進行 | 欠け、光路、中断、キー競合などを修正予定 | 前回レビューの問題が残る |
| ランキング | 今回は接続せず端末内版を整える | 端末内の試作処理とプレビュー用SQL |
| 依存構成 | R1で検査可能な構成を固定 | Vite・React・Tailwindの試作用構成 |
| 素材 | 独自SVG・端末フォント・合成音を基本にする | インラインSVG、端末フォント、合成音 |
| 共有画像 | 新画面と整合する最終版を公開前に確認 | public/og.jpgとx-banner.jpgは試作候補 |

正式版へ一式をコピーせず、使える判定を必須検査付きで移します。旧試作内の切替表示や旧READMEを現行仕様として実装しないでください。サーバー抽選・ランキング・実験場登録は別作業です。
