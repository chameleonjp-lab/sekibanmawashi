# 石板の素材画像

2026-10-12のユーザー指定により、ChatGPTの標準画像生成で石の素材を新規に作成しました。既存作品の石板や写真素材は参照していません。

ゲームに同梱する画像は [`public/textures/stone-slate-v1.webp`](../../public/textures/stone-slate-v1.webp) です。1024×1024、WebP、394,436 bytes。元画像を縮小・圧縮し、石の表面の色に使用します。画像の明るさから作る小さな凹凸と粗さは見た目を整えるための近似で、実測した石の形ではありません。

完全な生成指示、原本と同梱画像のSHA-256、圧縮条件は [`stone-slate-v1.json`](../../public/textures/stone-slate-v1.json) に保存しています。

生成指示は「真上から見た灰色の石が全面を覆い、細かな粒・孔・浅い割れ目を持つ写真風の素材。照明を焼き込まず、文字・輪・印・発光・透かしを含めない」です。標準の画像生成を使い、別料金の画像生成用APIは使用していません。

three.jsは固定版0.180.0をゲームへ組み込み、外部の配信サイトからコードや画像を読み込みません。MITライセンス全文を [`public/third-party/three-LICENSE.txt`](../../public/third-party/three-LICENSE.txt) に同梱します。素材生成・ライセンスの記録は権利の独占や実在の石のスキャンを主張するものではありません。
