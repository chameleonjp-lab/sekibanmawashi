## 検証環境と制約

ローカルのブラウザ取得で、`agent-browser install` がChromeの配布情報取得時に `UnknownIssuer` で失敗した。証明書検証の無効化は行っていない。ブラウザ検査の成否は、実際に実行できた環境と分けて追記する。

標準の `npx playwright install chromium webkit` も配布CDNへの接続タイムアウトで失敗した。ローカルの `test:e2e` はブラウザ起動段階で失敗し、画面の検査条件は未実行。GitHub CIにはブラウザ導入・検査・証跡保存を追加した。ローカル取得失敗を画面不具合と同一視せず、CI結果は別記録にする。

iPhone実機、VoiceOver、ロック復帰、人による難度・操作感の受入は未実施。ブラウザ上のモバイル画面検査を実機確認とは呼ばない。

複数指・pointercancel・lostpointercaptureはブラウザ内でイベントを送る模擬検査。通常のタップ・互換クリック・キー・画面外での指離し相当はブラウザの操作APIを使うが、実機2本指の挙動を確認したとはしない。文字200%はルート文字サイズを2倍にする自動検査であり、iPhoneの文字拡大設定そのものではない。

## 初回CIと修正

初回head `2ae95b459617a40fe2b407c7de22ab832790b670` の[CI 35623204514](https://github.com/chameleonjp-lab/sekibanmawashi/actions/runs/35623204514)では、ブラウザ導入に成功。画面検査は14成功・8失敗だった。失敗8件は、盤面の幅を固定したまま高さだけ制限して非正方形になったことによるV01/V02/V03の失敗。許容値を広げず、幅を画面の高さでも制限する正方形の配置へ修正した。

再検査用headは `ba2bc20c53828d46d80da2f4ca93ecfb9a1a2b7b`、treeは `bcd2e99a31b0936ea5d24c92920b6b45b487be62`。ローカルの対応コミット `cf7596a3f1b9b838357c084831bc35d9e0eb4959` は同一tree。GitHub経由で記録したコミットとローカルのコミットは記録者情報が異なるが、検査対象の内容は一致する。

修正後、`npm ci → typecheck → lint → test（40件）→ puzzles:test → build` がローカルですべて成功。ブラウザ検査は13件×2種類＝26件へ拡充した。

2回目の[CI 35623873979](https://github.com/chameleonjp-lab/sekibanmawashi/actions/runs/35623873979)は20成功・6失敗。両ブラウザで同じ3件が失敗した。

- 光のフィルター検査が、仕様にない原点-50を要求していた。実装の0〜300は光路18〜282とぼかし・線幅の余白を収めるため、実際の光路の両端＋10単位の余白を検査するよう修正。独立レビューで妥当性を確認した。
- 文字200%の1280×720で、状態欄の最小列幅による横スクロール58pxを検出。
- 通常文字375×667で回転ボタン下端688pxとなり、1画面に収まらなかった。

CIの失敗画像を取得し、実際の表示を確認して修正する。成功率だけで受入を決めず、最終の全件成功を別に記録する。

3回目の[CI 35624855628](https://github.com/chameleonjp-lab/sekibanmawashi/actions/runs/35624855628)は24成功・2失敗。全90問、文字200%、入力の検査は両ブラウザで成功。通常文字375×667だけ回転ボタン下端が675.25px（WebKitは675.22px）となった。見出し下の余白を1.25remから0.5remへ変更し、通常文字で12pxを確保した。文字・盤面・ボタンの縮小や合格条件の変更はしていない。

この1行のCSS修正も独立レビューで確認済み。再検査の実装headは `08d9d40e485120bf4470afb13a335217f9cbad32`、treeは `5f9c7e1de951eecddf5475fa46c3e0d0e95fc9dc`（ローカル `8250e389ac14e9abb2b68efb3733f8a0d2293b4d` と同一）。

## 検証環境の修正

CIで既存Vite 7.1.7の脆弱性警告を検出した。開発用サーバーを使うR3の検査基盤に関係するため、独立レビュー後、Viteのみ同じメジャー版の7.3.6へ更新した。既定の開発用サーバーも `127.0.0.1` の端末内限定とした。他の既存依存を広範囲に更新していない。

更新前は `npm audit` でhigh 1件、更新後は0件。これは実行時点の依存検査結果であり、将来を含む安全性の保証ではない。[Vite公式のWebSocket勧告](https://github.com/vitejs/vite/security/advisories/GHSA-p9ff-h696-f583)、[Windowsパスの勧告](https://github.com/vitejs/vite/security/advisories/GHSA-fx2h-pf6j-xcff)を確認した。

初回CIはNode 24.19.0同梱のnpm 11.17.0だったため、CIでも明示的にnpm 11.9.0を導入し、リポジトリの指定に揃えた。ローカルはNode 24.19.0 / npm 11.9.0。ブラウザ検査はUbuntu上のChromium/WebKitであり、iPhone実機ではない。
