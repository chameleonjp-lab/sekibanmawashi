# 2026-09-28の画面改善

対象: `chameleonjp-lab/sekibanmawashi`

## ユーザーが依頼した変更

- 石板の石らしい質感を改善し、石板全体を大きくする。
- 光を止める部品を記号だけで示さず、その場所の輪の区画を黒く塗る。
- 操作中に画面全体が上下へ動かないようにする。
- ゲーム画面から音設定を外す。ホームの音設定は残す。
- 問題・点灯などの状態表示欄を低くし、文字サイズも調整する。
- 専門用語を簡単な言葉へ置き換える。
- 成功時に左右から紙吹雪を出し、完成盤面を1.5秒表示してから次の問題へ進む。

## 実装・検査の判断

輪の遮断場所は12方向の1区画（30度）を黒く塗る。輪の押し分け、判定、手数、90問・900組の内容には手を加えない。成功後の1.5秒は問題時間に含めず、その間は完成した盤面を表示する。5問目も同じ演出を見せてから結果画面へ進む。

音の保存値とホームでの変更は維持し、ゲーム画面の設定だけをなくす。用語は「環」から「輪」、「受光紋」から「目標」、「点灯数」から「光った目標」などへ置き換える。動きを減らす設定では紙吹雪の移動を控えるが、待ち時間は1.5秒に保つ。

作業は最新mainから切ったブランチで行い、Draft PRを作成する。マージ、本番公開、実験場側の変更は行わない。iPhone実機で確認していない操作を実機確認済みと扱わない。
