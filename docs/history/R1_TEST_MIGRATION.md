# R1 旧17検査からの移行記録

旧 `prototype/` の17検査は、発光切替を含むv1の状態を対象にしていました。正式版R1は回転だけのv2を別実装として作るため、旧テストファイルをコピーせず、検査意図を次のK01〜K07へ移します。`prototype/` は比較資料として変更しません。

| 旧検査の意図 | v2での扱い | 理由 |
|---|---|---|
| 左右回転の境界 | K01 | 操作規則を維持する |
| 内向き・外向きの遮断 | K02 | 発光紋を含む遮断規則を維持する |
| 光の交差・余分な光・必須点灯 | K03 | 光どうしを遮らず、点灯を集合で判定する |
| 発光状態を含む符号化 | K04 | 発光状態を除き、1,728個の回転状態へ置換する |
| 切替を含む手数と再生 | K05 | 選択0手、回転1手、入力直後確定の履歴へ置換する |
| 旧形式の異常値 | K06 | 版、型、範囲、checksum、履歴境界を実行時に検査する |
| 発光切替音を含む参照 | K07 | 切替参照を正式版から除き、音の設定だけを残す |
| solverの代表解再生 | R2 P01〜P03 | 回転だけの探索と全状態の独立照合は、問題庫の成立条件と一緒に検査する |
| 90問の難度・初期完成・解なし・重複 | R2 P01、P04、P06 | R1は単一問題の形式を検査し、採用数と難度条件は問題生成後に確定する |
| 900券の順序・重複・出現回数・抽選分布 | R2 P07〜P09 | R1で問題庫や抽選券を仮採用せず、v2問題の検査後に固定する |

旧版固有の「停止した発光紋」「切替1手」「切替を含む13,824状態」は、新仕様と意味が異なるため正式版検査へ引き継がず置換しました。旧ファイルと履歴は保持し、検査数を揃えるための空テストは追加していません。

K03の同じ受光紋への複数到達は、人工的な遮断規則の例外を作って成立させません。同じ方向を向く発光紋は内側の発光紋が外側の光路を遮るため、外側の発光紋が同じ受光紋へ二重到達することはありません。実装はそれぞれの光路を追跡し、点灯区画と必須点灯数をビット集合で一度だけ加算することで、将来別の配置から同じ到達が返っても二重計上しないことを検証します。

R1のテストは `src/core/engine.test.ts` にあり、問題の形式、checksum、旧キー、欠落番号、小数環、負時刻、最初の成功後の余分な操作、同時刻の合法操作を含みます。問題形式の有効データ例は [rotation-only-v2.json](../../content/examples/rotation-only-v2.json) です。
