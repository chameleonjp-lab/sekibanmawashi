# 石板リング解錠ゲーム 計画書一式

このフォルダには、ChatGPT Workへ渡す実装計画書と、承認済みの石板画面案が入っています。

## 現在の競技仕様

- 日付では問題を切り替えません。
- 初級30問、中級30問、上級30問の合計90問を公開前に固定します。
- 1回の挑戦では、初級2問、中級2問、上級1問の合計5問をサーバーが抽選します。
- 5問の実測合計時間を競います。
- 抽選した5問はプレイ識別子へ固定し、未完了の挑戦で引き直せないようにします。

## ファイル

- `IMPLEMENTATION_PLAN.md`  
  6件のPRへ分けた実装計画書です。GitHubへ入れる場合は、`docs/IMPLEMENTATION_PLAN.md`として配置してください。

- `REFERENCE_STONE_TABLET_UI.png`  
  画面構成の参考画像です。ゲーム画面へ画像として貼り付けたり、部品を切り抜いて素材化したりせず、CSSと独自SVGで描き直してください。

- `puzzle-definition.example.json`  
  1問分のデータ形式例です。本番問題としては使いません。

- `problem-pool.example.json`  
  90問問題庫と抽選条件の形式例です。本番問題庫としては使いません。

## 重要

正式なゲーム名、リポジトリURL、公開URL、実験場URL、Supabaseプロジェクトは未確定です。計画書の第26章へ記入してから、PR1を開始します。
