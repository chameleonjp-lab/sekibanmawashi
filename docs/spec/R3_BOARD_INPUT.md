# R3 盤面と入力

規則の正本は[現行仕様](CURRENT_GAME_SPEC.md)、受入条件は[計画書 第5節](../planning/IMPLEMENTATION_PLAN.md)。R3は正式版の1問表示・操作までとし、5問の進行・正式な時計・保存・結果・共有はR4以降で整備する。

## 守る境界

判定は `src/core/` が返す光路を用いる。表示側で遮断物を探索し直さない。回転を受け付けた時点で状態・手数・履歴・成功を確定し、表示の完了を待たない。発光の切替操作を追加しない。

環の選択は0手。左右回転は1手。説明・中断確認、カウントダウン、成功後、無効な問題・終了済みの操作では盤面を変更しない。タップ、クリック、キー操作が同じ受付条件を通ることを検査する。

Enter/Spaceはフォーカス中のボタンだけを実行する。キーの押しっぱなしによる自動連打は設けない。入力欄や日本語変換中にゲーム用のキー操作を割り込ませない。説明・確認では背景を操作不能にし、閉じると元の操作へフォーカスを戻す。

## 検査範囲

通常の起動では採用90問の先頭1問を表示する。`puzzleId`の指定は1問確認用であり、900組からの正式なチャレンジ抽選ではない。不明なID・無効な問題は読込エラーとし、別問題や旧形式の例に差し替えない。画面の「時間」は未計測と明示し、正式な時計の完成を装わない。

盤面は300×300の共通座標系を使い、中心は(150,150)。環の選択領域は中心から31〜55、61〜85、91〜115の範囲で互いに分離する。受光紋の中心半径は132で、必須受光紋の二重円と線幅を表示範囲に収める。実際の画面での幅は盤面の表示倍率に応じて変わるため、HTMLの環選択ボタンも設ける。

| 検査 | 対象 |
|---|---|
| V01 | 採用90問・12方向の受光紋、外枠、線幅・光の余白 |
| V02 | 指定10画面寸法、200%文字拡大、横スクロール・重なり・操作到達 |
| V03 | 3環の選択領域と主要ボタン48×48px以上 |
| V04 / V05 | 判定と描画の終点、遮断印、12方向の光、表示の重ね順 |
| I01 / I03 | 明示的な1入力につき1回、互換クリック・長押し・複数指・キャンセル |
| I02 | 操作受付条件と成功後の固定 |
| I04 / I05 | 通常ボタン操作、変換中の保護、フォーカス、Escape、ラベルと通知 |
| I06 | タップのみ・キーボードのみの解答。VoiceOver実機は別記録 |

画面寸法は320×568、375×667、390×844、402×874、430×932、844×390、1280×720、393×852、852×393、1440×900。文字拡大時は操作への到達を優先し、必要な縦スクロールを許可する。

実行結果と未確認は[R3検査記録](../reviews/R3_VERIFICATION.md)へ記録する。Linux上のChromium/WebKitによる検査と、iPhone Safari・VoiceOverの実機確認は区別する。
