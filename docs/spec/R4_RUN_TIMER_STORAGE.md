# R4 5問進行・時計・端末内保存

更新日: 2026-09-21 / 計画: [対応実装計画書2.0](../planning/IMPLEMENTATION_PLAN.md) 第6節

この文書はR4の実装境界をまとめる。検査の成否と未確認は[R4検査記録](../reviews/R4_VERIFICATION.md)で区別する。実装・自動検査・独立レビュー済み。実機受入と公開準備は未完了。

## 画面の状態

| 状態 | 盤面操作・時計 | 次の操作と遷移 |
|---|---|---|
| ホーム | 操作なし・計測なし | 有効な名前でチャレンジまたは練習を開始 |
| 問題の取得・検査 | 操作なし・計測なし | 問題庫・券・割当を検査。失敗時は開始せず案内 |
| 最初の3秒 | 操作なし・計測なし | 同じ挑戦が有効な場合だけ問題1へ |
| 問題を解く | 選択・回転可、時計が進む | 成功入力でその問題の時間・手数・履歴を確定 |
| 説明・中断確認 | 背後の操作不可、問題の時計は進む | 閉じれば同じ盤面。中断を確定すれば挑戦を破棄 |
| 問題1〜4の成功表示 | 操作なし・時計停止 | 原則1,000ms後に次問を表示し、同時に計測開始 |
| 問題5の成功・結果 | 操作なし・時計停止 | メモリ上の結果を表示。その後に保存し、失敗しても結果を残す |

古い挑戦や問題の予約処理を、新しい画面へ反映しない。中断・再開始・破棄では予約を取り消し、処理時にも挑戦と問題を照合する。カウントダウンは挑戦の最初の1回、問題間表示は4回だけ。

## 抽選と練習

採用済み90問と900券を検査し、初級・初級・中級・中級・上級の5問を1組として扱う。問題IDは重複させず、プレイ中に差し替えない。単一問題の `?puzzleId=` 指定は盤面の確認用で、チャレンジの割当ではない。

未完了チャレンジの割当は端末内で30分保持する。再開始では盤面を復元せず、同じ割当の問題1から始める。端末時刻の逆行で期限を延長しない。保存不能時は制約を知らせ、参考記録としてプレイ可能にする。これは不正防止の保証ではない。

練習は同じ難度構成を別に抽選し、チャレンジの割当を上書きしない。「今の問題をやり直す」は操作可能中だけ受け付け、その問題の時計・手数・履歴だけを戻し、前問の確定記録は維持する。成功表示中はやり直しを受け付けない。

## 時計と参考記録

操作可能になった瞬間から、成功入力を受け付けた瞬間までを整数ミリ秒で記録する。画面表示は100分の1秒へ切り捨て、合計は5件の未丸め整数を足す。説明・中断確認・背面時間は含め、取得・最初の3秒・問題間表示は除く。

単調増加する時計と端末時刻を比較し、復帰イベントの重複で二重加算しない。通常時の時計差は5,000msを超えた場合に異常とする。60,000msを超える端末時刻の飛びも、両時計の差と併せて判定する。正常な両時計で単に長い時間が経ったことは異常にしない。逆行は境界ごとに検出する。

休止で片方だけ停止した区間は、長い側の経過を一度だけ取り込み、両時計の起点をそろえ直す。成功入力で得た読取値を再計測せず固定する。異常時も結果は表示し、自己ベストへ混ぜない。これらの閾値はR4の実装値であり、iPhone実機のロック復帰による受入は未完了。

1問題300手・合計1,500手・合計15分を超えても自動敗北にしない。参考結果まで進め、保持する操作履歴を制限する。

## 保存と共有

名前、音の設定、説明確認、版付きのチャレンジ自己ベスト、未完了検出、割当を検証付きで扱う。名前は1〜16文字で、空白だけ・制御文字を拒否する。異常な項目だけを初期化し、読込例外や容量不足を画面全体の失敗へ波及させない。

旧版は有効な名前と音設定だけ移行する。旧成績、盤面、未送信記録、端末IDは移行・送信しない。旧保存キーを一括削除しない。別タブの古い値で良い記録を下げない。

結果には5問の難度・時間・手数、合計、再挑戦・練習・ホーム・実験場へ戻る操作を置く。共有は端末の共有機能、コピー、選択可能な文面の順に対応する。共有の取消しではコピーせず、成功とも表示しない。

ゲーム名は仮表示の「石板回し」、ゲームURLは既存計画の予定URLを使う。正式公開名・共有画像の確定や本番公開を意味しない。順位や送信成功を装う表示、ランキング・プレイ回数の通信は追加しない。
