# 現在のゲーム仕様

状態: 採用済み。実装前
実装の詳細: [`../planning/IMPLEMENTATION_PLAN.md`](../planning/IMPLEMENTATION_PLAN.md)

## 何を作るか

石板に刻まれた3本の環を回し、発光紋と遮断石の位置関係を変えて、外周の必要な受光紋をすべて点灯させるパズルゲームです。1回で5問を続けて解き、実際に操作できた時間の合計を競います。

既存作品の画像、音、固有名称、問題配置、文章、完成演出は使いません。調査した仕組みを、独自の規則、問題、石板画面、コードで作り直します。

## 盤面と部品

- 円周を12方向へ分け、回転できる環を3本置きます。
- 発光紋は、中心を通って反対方向へ光を出します。
- 遮断石は、そこへ来た光を止めます。
- 発射元ではない発光紋も光を止めます。停止中の発光紋も石の部品として光を止めます。
- 光同士が中心で交差しても、互いを止めません。
- 外周の必須受光紋がすべて点灯すれば成功です。必須でない方向へ光が出ても失敗にはしません。

## 操作

プレイヤーは盤面の環を直接タップして選びます。左回転または右回転を押すと、選んだ環が1区画だけ動きます。選択中の環にある発光紋は、まとめて発光と停止を切り替えられます。

環を選ぶだけでは手数に数えません。左右の回転と発光の切替を、それぞれ1手と数えます。正式競技では問題のやり直しを置きません。練習では現在の問題を最初からやり直せます。

入力した瞬間に内部状態と成功判定を確定します。回転アニメーションは結果を後から見せるためのもので、端末の描画速度をタイムへ混ぜません。

## 1回の挑戦

公開前に、初級30問、中級30問、上級30問の合計90問を作ります。解けない問題、開始時点で完成した問題、難度から外れる問題、実質的に同じ問題は採用しません。

1回の競技は次の順です。

1. 初級
2. 初級
3. 中級
4. 中級
5. 上級

5問はサーバーが重複なしで選び、挑戦専用の識別子へ固定します。中断や再読込を使って都合のよい問題へ引き直すことはできません。日付による問題切替は行いません。

同じ難度でも問題差が大きくならないように、最短手数、最短解の数、発光切替の必要回数、解法の分岐などを使って問題を校正します。さらに5問の難しさの合計が一定範囲に入る抽選券を900件作り、各問題の出現回数をそろえます。公開前に10万回の抽選試験を行います。

## 時間と順位

各問題は、盤面を実際に操作できるようになった瞬間から、成功する入力を受け付けた瞬間までを整数ミリ秒で測ります。カウントダウン、読み込み、問題間の演出は合計へ含めません。画面を背面へ移しても競技時間は止まりません。

順位は次の順で決めます。

1. 5問の合計時間が短い
2. 同じ場合は総手数が少ない
3. それも同じ場合は有効記録の送信が早い

問題庫を変更した場合は`poolVersion`を上げ、変更前後の記録を同じランキングへ混ぜません。

## 記録の検証

ブラウザが送った合計時間だけでは正式記録にしません。どの環をいつ、どちらへ動かし、発光をどう切り替えたかを保存します。サーバーは割り当てた5問を同じ規則で再生し、5問すべてが正しく解けた場合だけ記録します。

同じ挑戦を二重送信しても記録を増やしません。送信に失敗した結果は端末に残し、結果画面から再送できるようにします。秘密鍵はブラウザ、GitHub、公開JavaScriptへ置きません。

## 画面

主対象はiPhone Safariの縦画面です。問題番号、難度、タイム、点灯数、盤面、環の選択状態、左右回転、発光切替、手数、中断を一画面に収めます。常設の長い説明欄や、盤面より目立つ装飾は置きません。

主要な操作領域は48ピクセル以上を基本とし、320×568から430×932まで横スクロールなしで使えるようにします。色だけに頼らず、形と模様でも部品を区別します。横画面とパソコンにも対応しますが、スマートフォン版の規則や判定を変えません。

## ゲームモード

正式競技はランキングへ送ります。練習は同じ90問から5問を選びますが、ランキングへ送りません。競技中の一時停止とヒントは作りません。
