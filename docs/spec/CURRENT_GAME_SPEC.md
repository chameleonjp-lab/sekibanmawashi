# 現在のゲーム仕様

文書版: 2.1 / 更新日: 2026-09-29 / 状態: **基本機能実装済み。PR #17の画面仕上げはmainへマージ済み。実機受入とR6公開は未完了**

詳細と検査は[対応実装計画書](../planning/IMPLEMENTATION_PLAN.md)を使います。旧試作がこの仕様へ変更済みという意味ではありません。

## 何を作るか

石板の3本の輪を回し、光を出す点と光を止める黒い場所を動かして、外側の目標すべてに光を届けるパズルです。1回で5問を続けて解き、それぞれのプレイ時間を合計します。カメレオンJPの実験場のゲームとして公開できる品質へ整えます。

既存作品の画像、音、固有名称、問題配置、文章、完成演出は使いません。盤面は独自のSVG、操作部はHTMLで作ります。

## 盤面と光

外側には12方向の目標があり、回せる輪は3本です。光を出す点は**いつも光り、消す操作はありません**。光は中心へ進み、通り道が空いていれば反対側へ進みます。

黒い場所と、光を出していない点は光を止めます。光どうしが交差しても止まりません。すべての目標に光が届けば正解です。ほかの方向にも光が進んでかまいません。

石板は石の粒を見せる質感にします。遮断石がある方向は、輪の30度分を黒く塗って示します。光の道が遮断位置まで届いても、その黒い部分から先へは伸ばしません。

## 操作

輪を直接選び、左か右へ1つ分ずつ回します。選ぶだけなら回数に入りません。回すたびに1回です。左右以外の仕掛けを追加して、廃止した発光切替の代わりにしません。

操作を受け付けた時点で盤面と正解を確定します。PCは1/2/3・上下で輪を選び、左右で回します。Enter/Spaceは選んでいるボタンを押す操作だけに使います。

説明と中断確認を開いている間は、背後の盤面を操作できません。チャレンジの時間は進みます。音の有無はホーム画面で切り替え、ゲーム画面には音の設定を表示しません。

## 問題と難度

初級30問・中級30問・上級30問を用意し、初級、初級、中級、中級、上級の順に5問を出します。1回の挑戦で同じ問題を重複させず、挑戦中は問題を変更しません。日付では切り替えません。

旧90問は全て常時発光で再検査し、18問を再利用、72問を差し替えました。解けない問題、初期完成、難度外、回転・反転しただけの問題は採用しません。計画書の部品数・難度の初期案は `r2-config-v1` として数値を維持し、各難度300件の合格候補から30問を選べることを確認しました。詳しくは[R2問題生成](R2_PUZZLE_GENERATION.md)を参照してください。人による試遊は未実施です。

900組を作り、各問題の出現回数と初級2問・中級2問・上級単体・5問合計の難度範囲を同時に検査します。10万回の抽選試験も行いますが、異なる問題を引く以上、人が解く難しさまで完全に同一とは保証しません。

## 進行と時間

名前は開始前に必須で、1〜16文字です。5問のデータを検査してから最初だけ3秒のカウントダウンを行います。正解したら完成した盤面を1.5秒表示し、両側から紙吹雪を出してから次の問題へ進みます。5問目も演出後に結果を表示します。次問の追加3秒カウントダウンは入れません。

問題を操作可能にした瞬間から成功入力まで、整数ミリ秒で計測します。画面は100分の1秒まで表示しますが、合計は丸めていない5件の整数から求めます。カウントダウン、取得、問題間・結果の演出は合計に含めません。考える時間、説明、中断確認、背面へ移った時間は含めます。

次問を先に見せたまま計測を止めることはしません。画面回転・正常な離脱復帰で状態や時間を失わせません。再読込した未完了チャレンジは復元せず、中断したことを表示します。

## 今回のモードと保存

チャレンジと練習を用意します。チャレンジは問題のやり直しなし、練習は現在の問題をやり直せます。一時停止、ヒント、アカウントは追加しません。

**今回は記録を端末内に保存し、ランキングへ接続しません。** 画面でその違いを知らせ、順位や送信完了を装う表示は出しません。未完了の同じ版のチャレンジ割当は30分保持し、再開始時の引き直しを端末内で抑えますが、不正防止の保証ではありません。

旧版と新版、チャレンジと練習の記録は混ぜません。保存に失敗しても5問の結果と共有機能は利用できます。名前と音設定のみ検証して旧版から移行可能とし、旧成績を新規則の記録へ変換しません。

## 画面と結果

iPhone Safariの縦画面を主対象とします。石板は石らしい控えめな模様を付け、画面に合わせて大きく表示します。光を止める場所は印ではなく、その場所を黒く塗って示します。問題番号・難しさ・時間・光の届いた数・盤面・選ぶ輪・左右回し・回した数・遊び方・中断を、通常文字サイズの指定縦画面で収めます。状態欄の高さと文字は控えめにし、画面を動かしても盤面の位置が上下しないようにします。全ての目標と光の通り道が見え、描画と判定が一致することを優先します。画面の言葉は「目標」「輪」「回した数」など、初めて遊ぶ人に伝わる表現を使います。

主要ボタンは48×48px以上。環は誤って隣を選ばない領域を設け、キーボード・読み上げでも選べるようにします。説明と結果の必要な縦スクロールは残し、文字拡大を読めない縮小で打ち消しません。色だけで部品を区別しません。

結果は5問それぞれの難しさ・時間・回した数と合計を表示し、再挑戦、練習、ホーム、実験場へ戻る操作を用意します。ホームと結果のシェアにはゲームURLを含め、共有を取り消したら勝手にコピーしません。

## 今回変更しない外部機能

サーバー抽選、順位の登録・取得・上位表示、プレイ回数連携は延期します。将来の記録比較順は合計時間、総手数、有効送信時刻の順とする従来方針を残しますが、今回は実装・接続・本番データ変更をしません。

正式名、共有画像、実験場への掲載方法を推測で確定しません。本番公開はゲーム本体の受入、実機確認、ユーザーの公開指示の後に別段階で行います。
